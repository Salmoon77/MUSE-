# **개인정보 보호정책 (Privacy Policy)**  

**최종 업데이트: 2025년 2월 12일**  

**1. 개요**  
본 개인정보 보호정책(이하 "정책")은 디스코드 봇 **MUSE**가 사용자 정보를 어떻게 수집, 사용, 보호하는지에 대한 내용을 포함합니다. 봇을 사용함으로써 본 정책에 동의하는 것으로 간주됩니다.  

**2. 수집하는 정보**  
봇은 다음과 같은 데이터를 수집할 수 있습니다.  

- **서버 ID**: 서버별 설정을 저장하기 위해 수집됩니다.  
- **메시지 내용 (Message Content, 선택적)**: 봇의 특정 기능(예: 뮤직채널)을 수행하기 위해 메시지 내용을 수집할 수 있습니다.  
  - 메시지 내용은 실시간으로 처리되며, 별도로 저장되지 않습니다.  
- **명령어 사용 기록**: 봇 명령어의 사용 빈도 및 패턴을 분석하여 서비스 개선에 활용할 수 있습니다.  

**3. 정보 사용 목적**  
수집된 정보는 다음과 같은 목적을 위해 사용됩니다.  

- 봇의 정상적인 기능 제공  
- 사용자의 환경을 저장하고 맞춤형 기능 제공  
- 버그 수정 및 성능 개선  

**4. 정보 공유 및 공개**  
봇은 수집한 정보를 제3자에게 판매하거나 공유하지 않습니다. 단, 다음의 경우에 한하여 공개될 수 있습니다.  

- 법적 요구에 따른 공개 (예: 법원의 명령, 정부 기관 요청)  
- 디스코드 약관 및 정책 준수를 위한 경우  

**5. 데이터 보안**  
봇은 사용자 데이터를 보호하기 위해 다음과 같은 보안 조치를 적용합니다.  

- Discord의 **OAuth2 인증**을 사용하여 사용자 정보를 보호  
- 서버 내 데이터 저장 시 **암호화된 데이터베이스** 사용  
- 민감한 데이터는 저장하지 않으며, 필요 시 즉시 삭제  

**6. 데이터 보존 기간**  
봇은 사용자 데이터를 필요한 기간 동안만 보관하며, 다음과 같이 처리됩니다.  

- 사용자 요청 시 언제든지 데이터 삭제 가능  
- 장기간 사용하지 않는 데이터는 자동 삭제  

**7. 사용자의 권리**  
사용자는 언제든지 자신의 데이터를 조회, 수정, 삭제 요청할 수 있습니다.

# **Privacy Policy**  

**Last Updated: February 12, 2025**

  - Message content is processed in real-time and is not stored separately.
